# Telegram Username Checker Bot

Бот для проверки занятости юзернеймов для БОТОВ в Telegram с неограниченным количеством проверок.

## Функции

- ✅ **Неограниченное количество** юзернеймов за раз
- ✅ **Проверка базовых имен** (без суффиксов)
- ✅ **Автоматическая генерация вариантов** с суффиксами bot/_bot
- ✅ **Прогресс-индикатор** в реальном времени
- ✅ **Проверка через Telegram Bot API** (надежно)
- ✅ **Разделение результатов** на свободные и занятые

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите бота:
```bash
python bot.py
```

## Использование

Отправьте боту базовые имена для проверки:
```
zalupa122
koch121
fog229
```

Или через пробел/запятую:
```
zalupa122, koch121, fog229
```

## Логика работы

1. Проверяет базовое имя (без суффиксов)
2. Если базовое имя свободно → проверяет варианты с суффиксами
3. Если базовое имя занято → варианты считаются занятыми
4. Показывает прогресс проверки каждого юзернейма

### Файлы для деплоя

- `bot.py` - главный файл бота

1. Загрузите файлы на GitHub
2. Создайте проект на Railway
3. Настройте переменную окружения `BOT_TOKEN`
4. Бот будет работать 24/7

## Особенности

- **Без ограничений** - можно проверять сотни юзернеймов за раз
- **Быстрые таймауты** - не зависает при проверке
- **Надежная проверка** - через официальный Telegram Bot API
- **Прогресс-индикатор** - видите проверку в реальном времени
